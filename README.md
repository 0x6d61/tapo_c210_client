# Tapo C210 Client

Java で Wi-Fi カメラへ接続するクライアントです。開発ルールは [AGENTS.md](AGENTS.md) を参照してください。

## 前提環境

- Java 21 以上
- Maven 3.9 以上

## ビルドとテスト

```text
mvn verify
```

カメラ実機に依存しないテストを標準のビルドに含め、実機を使う統合テストは別途明示的に実行できる構成にします。

## 現在の状態

次の基盤を実装済みです。

- C210の接続プロファイルとRTSP高画質／低画質のドメインモデル
- SQLiteへのプロファイル・平文パスワード保存と再起動後の復元
- 保存済みプロファイル一覧の取得
- 保存済みプロファイルを選択したRTSP接続要求の生成
- パスワードをログや接続要求の文字列表現へ出さない境界
- JavaFXの接続先選択画面、手動接続フォーム、入力エラー表示
- OSごとのアプリケーションデータディレクトリへのSQLite接続
- ONVIF WS-DiscoveryのProbe生成、ProbeMatch解析、UDP検出、重複排除
- JavaFXからの非同期カメラ検索と検出結果の接続フォーム引き継ぎ
